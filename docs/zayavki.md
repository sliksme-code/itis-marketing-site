# Заявки с сайта: Telegram-бот и почта

Форма на любой странице отправляет заявку на `/api/lead`. Приёмник (`server/lead.mjs`) пересылает её **в Telegram** и **на почту**. В заявке — имя, телефон, задача, страница сайта и рекламная метка (utm), с которой пришёл клиент.

Каналы работают независимо: если один недоступен, заявка уйдёт через второй. Каждая заявка дублируется в лог приложения в Timeweb — даже если оба канала упадут, её можно найти там.

Защита от спама: скрытое поле-ловушка для ботов и не больше 5 заявок с одного IP за 10 минут.

---

## Шаг 1. Telegram-бот — 5 минут

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя: `itis заявки`, логин: например `itis_leads_bot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `7712345678:AAH...` — это `TG_BOT_TOKEN`. Никому его не пересылайте.
4. Создайте группу «Заявки с сайта», добавьте в неё бота и всех, кто должен видеть заявки (Марат, Гульназ).
5. Напишите в группе любое сообщение, например «тест».
6. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…` — это `TG_CHAT_ID` (число со знаком минус, его нужно скопировать целиком).

> Если `getUpdates` пустой — отправьте в группу ещё одно сообщение и обновите страницу. Если группа потом станет «супергруппой», id поменяется — повторите шаг 6.

Можно слать заявки сразу в несколько чатов: перечислите id через запятую.

## Шаг 2. Почта — 5 минут

Нужен ящик-отправитель на вашем домене, например `site@itis.marketing`. Можно использовать и существующий ящик, но отдельный удобнее: его пароль знает только сайт.

Для ящика нужен **пароль приложения** (не обычный пароль от почты):

| Где почта домена | Где взять пароль приложения | SMTP_HOST | SMTP_PORT |
|---|---|---|---|
| Яндекс 360 | id.yandex.ru → Безопасность → Пароли приложений → Почта | `smtp.yandex.ru` | `465` |
| Mail.ru для бизнеса | Настройки → Безопасность → Пароли для внешних приложений | `smtp.mail.ru` | `465` |
| Google Workspace | myaccount.google.com → Безопасность → Пароли приложений (нужна 2FA) | `smtp.gmail.com` | `465` |

Получатели — `LEAD_EMAIL_TO`: например `marat@itis.marketing`, при необходимости через запятую добавьте адрес менеджера проекта.

## Шаг 3. Переменные в Timeweb

Timeweb Cloud → Apps → приложение сайта → **Настройки → Переменные окружения**. Добавьте:

| Переменная | Пример |
|---|---|
| `TG_BOT_TOKEN` | `7712345678:AAH...` |
| `TG_CHAT_ID` | `-1001234567890` |
| `SMTP_HOST` | `smtp.yandex.ru` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `site@itis.marketing` |
| `SMTP_PASS` | пароль приложения из шага 2 |
| `LEAD_EMAIL_TO` | `marat@itis.marketing` |

Сохраните и нажмите **«Перезапустить»** (или сделайте новый деплой).

Значения храните только в Timeweb — в репозиторий их не добавлять.

## Шаг 4. Проверка

1. Откройте `https://<адрес сайта>/api/health` — должно быть `{"ok":true,"channels":["telegram","email"]}`. Если какого-то канала нет в списке — для него не заданы переменные.
2. Отправьте заявку с любой страницы: она должна прийти в группу Telegram и на почту за несколько секунд.
3. Если не пришло — Timeweb → Apps → **Логи**: ищите строки `[lead]` с текстом ошибки.

| Ошибка в логах | Что сделать |
|---|---|
| `Telegram 401` | Неверный токен — скопируйте заново из @BotFather |
| `Telegram 400: chat not found` | Неверный `TG_CHAT_ID` или бот не добавлен в группу |
| `Telegram 403` | Бота удалили из группы — добавьте снова |
| `Invalid login` / `535` | Неверный пароль приложения или логин ящика |
| `ETIMEDOUT` при отправке почты | Порт закрыт у хостинга — попробуйте `SMTP_PORT=587` |

## Шаг 5. Цель в Яндекс Метрике (после подключения счётчика)

Метрика → Настройки → Цели → Добавить цель → **JavaScript-событие**, идентификатор `lead`. Сайт отправляет это событие при каждой успешной заявке — так видно, сколько заявок дал каждый рекламный канал.
